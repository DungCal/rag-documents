## 4. INSPECTING ELECTRO HYDRAULIC SYSTEM

![](b3c25821a09a2ad1f8248ecaa371f27aa8c17e09aa8ba47fbae2b3410e8de3da.jpg)

When calibration fails, or re-enter to calibration mode;

1. Disconnecting sensor connector while start switch is on position.

2. Confirm error code 22.

3. Turn start switch to OFF position.
Re-assembly sensor module.

4. Start the engine.

5. Confirm 44 of status led(calibration mode) is on, then try again from 1

^{st}

step.
